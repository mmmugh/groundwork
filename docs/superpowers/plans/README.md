# Plans

The implementation plans the course was built from, in order; the roadmap comes first. They are historical records,
kept as they were written, so they use the course's earlier name, Java Foundations, and they cite places that are not in
this repository:

- `WORKSHEET-*.md` and `spike/2026-09-27/`: the author's working notes and a first-day spike, kept private (D95). A
  decision they cite by number (D, J or R) is in [DECISIONS.md](../../../DECISIONS.md).
- `~/java_foundations-notes`, `~/groundwork-notes` and "SDD" workspaces: the author's private research notes and the
  ledgers of the subagent-driven runs that executed each plan.
- `~/python_foundations`: the author's working copy of the Python course. Port 8731 is its dev server's.

Three things were changed after the fact: a path in 2026-10-05-plan-4.md that named the author's home folder, two
details of the author's own machine and network (a memory size in 2026-09-28-plan-3-page.md, a home network in
2026-09-30-plan-3b-scratchpad.md), and the author's first name, which these plans now write as "the author" (the bylines in DESIGN.md and in DECISIONS.md's D25
are the only places it stays).
