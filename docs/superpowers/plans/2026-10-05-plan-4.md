## Review Focus

The five inputs or conditions most likely to bite a reader or a self-hoster that no earlier test exercises. Each has its
test in the owning task.

1. **A self-hoster serves the zip with stock nginx** (no `.mjs` type; older nginx has no `.wasm` either): the page, its
   boxes, a stack trace and the scratchpad must all work. Test: Task 2 Step 1(b) and Task 8 Step 4 (a server that knows
   only .html, .css, .js, .json and .txt).
2. **A reader opens a self-hosted page on a LAN address over plain http** (no crypto.subtle, no Cache Storage): the
   scratchpad starts, its download is still checked, and its words promise nothing that is false there. Test: Task 3
   Step 6, a real insecure origin in all three engines, preconditions asserted.
3. **A reader pastes a program that tries to phone home** (java.net.URL, HttpURLConnection): it fails as on a computer with
   no network, nothing leaves the page, and the next run works. Test: Task 4 Step 5, all three engines, no CSP header (the
   doors, not a header the shipped site never sends, must be what stops it), a live server that must see no connection.
4. **A fresh clone fetches the published releases through GitHub's redirect** (a release asset URL answers 302 to another
   host): both fetches follow it, verify every byte, and never leave a bad file or a half-made release in place. Test: Task 5
   Step 1, both fetches, with a one-byte-changed file and a 404 behind the redirect [C2, B11].
5. **The site is served from a subpath**, as Pages serves https://mmmugh.github.io/groundwork/: every page, script, worker
   and download resolves under the prefix. Test: Task 8 Step 4, the unzipped site served under `/groundwork/` with
   everything outside the prefix answering 404, and every request checked to start with the prefix [B14].

  0x6a09e667, 0xbb67ae85, 0x3c6ef372, 0xa54ff53a, 0x510e527f, 0x9b05688c, 0x1f83d9ab, 0x5be0cd19]);

const rotr = (x, n) => (x >>> n) | (x << (32 - n));

export function sha256Hex(input) {
  const bytes = ArrayBuffer.isView(input) ? new Uint8Array(input.buffer, input.byteOffset, input.byteLength)
    : new Uint8Array(input);
  const h = H0.slice(), w = new Uint32Array(64);
  const block = (view, off) => {
    for (let t = 0; t < 16; t++) w[t] = view.getUint32(off + 4 * t);
    for (let t = 16; t < 64; t++) {
      const a = w[t - 15], b = w[t - 2];
      w[t] = (w[t - 16] + (rotr(a, 7) ^ rotr(a, 18) ^ (a >>> 3)) + w[t - 7] + (rotr(b, 17) ^ rotr(b, 19) ^ (b >>> 10))) | 0;
    }
    let a = h[0], b = h[1], c = h[2], d = h[3], e = h[4], f = h[5], g = h[6], k = h[7];
    for (let t = 0; t < 64; t++) {
      const t1 = (k + (rotr(e, 6) ^ rotr(e, 11) ^ rotr(e, 25)) + ((e & f) ^ (~e & g)) + K[t] + w[t]) | 0;
      const t2 = ((rotr(a, 2) ^ rotr(a, 13) ^ rotr(a, 22)) + ((a & b) ^ (a & c) ^ (b & c))) | 0;
      k = g; g = f; f = e; e = (d + t1) | 0; d = c; c = b; b = a; a = (t1 + t2) | 0;
    }
    h[0] += a; h[1] += b; h[2] += c; h[3] += d; h[4] += e; h[5] += f; h[6] += g; h[7] += k;
  };
  const n = bytes.length, full = n - (n % 64);
  const view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
  for (let off = 0; off < full; off += 64) block(view, off);
  const tail = new Uint8Array(n - full < 56 ? 64 : 128);
  tail.set(bytes.subarray(full));
  tail[n - full] = 0x80;
  const tv = new DataView(tail.buffer);
  tv.setUint32(tail.length - 8, Math.floor(n / 0x20000000)); // the bit length's high 32 bits: floor(8n / 2^32)
  tv.setUint32(tail.length - 4, (n << 3) >>> 0);              // and its low 32 bits
  for (let off = 0; off < tail.length; off += 64) block(tv, off);
  return Array.from(h, (x) => x.toString(16).padStart(8, "0")).join("");
}

```js
// D86: once a worker has loaded what it needs, it closes every door to the network, so a reader's program talks to
// nobody. A door is removed from the worker's global object and from every object up its prototype chain.
// XMLHttpRequest stays as a stub that fails as XHR fails on a computer with no network, so java.net (TeaVM's
// XHRURLConnection) throws as Java does offline. import() cannot be removed; nothing a reader writes can call it once
// org.teavm.jso has left the compile classlib (S1, D46).
export const DOORS = ["fetch", "WebSocket", "WebSocketStream", "WebTransport", "EventSource", "Worker", "SharedWorker",
  "importScripts", "caches", "CacheStorage", "Cache"];

class OfflineXMLHttpRequest {
  open() {}
  setRequestHeader() {}
  overrideMimeType() {}
  abort() {}
  getAllResponseHeaders() { return ""; }
  getResponseHeader() { return null; }
  send() { throw new DOMException("This course's programs have no network.", "NetworkError"); }
}

export function closeNetworkDoors(scope = globalThis) {
  const remove = (name) => {
    for (let o = scope; o !== null; o = Object.getPrototypeOf(o))
      if (Object.prototype.hasOwnProperty.call(o, name) && !delete o[name]) throw new Error(`cannot remove ${name}`);
  };
  for (const name of [...DOORS, "XMLHttpRequest"]) remove(name);
  Object.defineProperty(scope, "XMLHttpRequest", { value: OfflineXMLHttpRequest, writable: false, configurable: false });
  for (const name of DOORS) if (name in scope) throw new Error(`${name} is still reachable`);
}
```
