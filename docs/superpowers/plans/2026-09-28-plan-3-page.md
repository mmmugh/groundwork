**Goal:** every box on a built page runs in the reader's browser. Run works in a Web Worker with a deadline and an
output cap; a program that asks a question stops, takes the answer in place, and runs again with the answers so far
(D16); Check judges method, input, output and predict exercises and says in plain words what is wrong; a browser that
cannot run Java says so and names the minimum versions; everything reads at 390 px. All of it is tested under Node and
in real Chromium, WebKit and Firefox.

**Architecture:** the environment-agnostic runner core Plan 1 wrote (`runtime/runner/tjava-core.mjs`,
`worker-protocol.mjs`) gains a "needs input" stop and caps, and a browser twin of `NodeRunner` (`web/runner/`) hosts it

under Node against `NodeRunner`; the DOM layer (`web/app.mjs`, `web/page/box.mjs`, `web/page/support.mjs`) is thin and
tested in browsers by Playwright against the built fixture volume served by `web/serve.mjs`. The build (Plan 2)
publishes the page's scripts by an explicit list and embeds each check in its own box.

Plan 2 (Java 25), Node 25, `playwright-core` (pinned) with Playwright's Chromium, WebKit and Firefox.

## Global Constraints

- Machine: no system JDK. `J=runtime/.work/jdk25/jdk-25.0.4.1+1/Contents/Home/bin/java`. Node is `node` (v25.9.0 here).
  `npm` is used only to install `playwright-core`.
- Never bind port 8731 (the Python course's dev server). `web/serve.mjs` defaults to 8740 and refuses 8731; every test
  serves on port 0 (an ephemeral port) on 127.0.0.1.
- The page talks to nobody: every request a page makes goes to its own origin, and the browser tests fail on any other.
  Nothing may need COOP/COEP headers (D7); the dev server sends none.
- Programs run in Web Workers: one long-lived compile worker per page, a fresh run worker per run, `terminate()` at the
  deadline. The page never runs Java on its own thread.
- Page limits: a run's deadline is 5,000 ms; output stops at 1,000,000 characters or 100,000 lines (the worker
  protocol's two caps; since Task 2 the line cap counts finished lines); a compile that takes longer than 60,000 ms counts as a crashed compiler.
- Browsers: current Chrome, Firefox and Safari, including iOS. The minimum versions a page names are Chrome 119,
  Firefox 120 and Safari 18.2 (macOS and iOS): the first versions with all three WebAssembly proposals that
  `compiler.wasm` and every compiled program use (WasmGC: 119/120/18.2; typed function references: 119/120/18; legacy
  exception handling: 95/100/15.2; MDN browser-compat-data). Support is detected by feature, never by user agent.
- 390 px: at a 390 px wide viewport, no page scrolls sideways; long code lines scroll inside their box.
- Reader-facing text: American spelling, closed em dashes (word—word), "course" not "book". Text the JDK prints is
  shown verbatim.
- Publishing by whitelist: a file reaches `site/` only because the build wrote it on purpose. Page scripts are copied
  by an explicit list; `Publish.guard` still scans everything afterward.
- Clean room (D14): only Tasks 2 and 11 change TeaVM. Its sources are TeaVM's own code (`runtime/.work/build/src/teavm/`), the
  public Javadoc and the pinned JDK's observed output. Nobody opens OpenJDK source: not `lib/src.zip`, not anything under
  `runtime/.work/build/src/teavm-javac/javac/build/`, not OpenJDK on the web. No other task touches `runtime/patches/`.
- New code files carry the Apache-2.0 header with `Copyright 2026 Java Foundations contributors` (in `.mjs`, the
  `/* */` block `runtime/runner/*.mjs` use; in HTML, the comment block `web/page.html` uses). Fixture volume data files
  carry none.
- Scripts exit 0 when every check passes, 1 when one fails, 2 on misuse. Test output follows
  `runtime/test/runner-safety.mjs`: one `  ok    <label>` or `  FAIL  <label>  got <json>` line per check.
- Scratch goes to `build/.work/` or `runtime/.work/` (git-ignored), never `/tmp`. `node_modules/` is git-ignored.

## Review Focus

1. **A typed answer with non-ASCII text (`café 😀`) or an empty answer (just Enter), through replay:** the transcript
   shows it exactly and the program receives it exactly. Tests: Task 4 (`replay.mjs`), Task 8 (browser).

   own line for their own errors, and never runs the reader's `main`. Tests: Task 5.
3. **Run pressed again, or Reset pressed, while a run or a replay is still going:** the old run stops, and none of its
   output lands afterward. Test: Task 8 (browser).
4. **Output printed without a newline right before a pause for input, or before a runaway loop:** the prompt is on
   screen. Tests: Task 2 (Node), Task 3 and Task 8 (browsers).
5. **An old browser (no WasmGC, no module scripts, or no JavaScript):** every page still reads; every box says the
   browser cannot run Java and names the minimum versions; no box offers a button that cannot work. Test: Task 7.
6. **A reader's edits when the page goes away (D41, D43):** an edited box keeps its code across a reload, and in
   Chromium across the tab crash a runaway allocation causes (Safari can lose the page the same way); Reset forgets the
   edit. Tests: Task 3 (the Chromium crash is pinned), Task 8 (browser).

Create `runtime/runner/java-line.mjs` (Apache-2.0 header):
```js
// The JDK's own first line for the two failures that never come back from a program as a Java exception (the
// fork cannot let a program catch them, DESIGN.md section 2). Shared by NodeRunner and the browser's
// BrowserRunner. Each signature is the exact error a JavaScript engine raised for that failure, recorded by
// runtime/test/runner-safety.mjs (Node) and web/test/runner.mjs (Chromium, WebKit, Firefox), so no other crash
// or trap is mislabeled as one of these.
export const OUT_OF_MEMORY = 'Exception in thread "main" java.lang.OutOfMemoryError: Java heap space';
export const STACK_OVERFLOW = 'Exception in thread "main" java.lang.StackOverflowError';
// status "trap": what runProgram's describeThrown reported for the error
export const STACK_OVERFLOW_TRAPS = [
  { jsType: "RangeError", message: "Maximum call stack size exceeded" }, // V8: Node, Chromium
];
export const OUT_OF_MEMORY_TRAPS = [];
// status "crashed": the message the runner recorded for a run worker that died
export const OUT_OF_MEMORY_CRASHES = [
  "ERR_WORKER_OUT_OF_MEMORY", // Node worker_threads
];
const matches = (list, e) => list.some((s) => s.jsType === e?.jsType && s.message === e?.message);
export function javaLineFor(status, exception) {
  if (status === "crashed" && OUT_OF_MEMORY_CRASHES.includes(exception?.message)) return OUT_OF_MEMORY;
  if (status === "trap" && matches(OUT_OF_MEMORY_TRAPS, exception)) return OUT_OF_MEMORY;
  if (status === "trap" && matches(STACK_OVERFLOW_TRAPS, exception)) return STACK_OVERFLOW;
  return null;
}
```

`web/runner/browser-runner.mjs` (Apache-2.0 header):
```js
// The page's runner: the browser twin of runtime/runner/node-runner.mjs, with the same result shape, so
// web/page/replay.mjs and web/page/check.mjs run unchanged against either. One long-lived compile worker per
// page; a fresh run worker per run, terminated at the deadline; a spare run worker kept warm.
import { javaLineFor } from "./java-line.mjs";

export class BrowserRunner {
  // base: the URL of the site root, which holds runner/ and runtime/.
  constructor(base, { compileDeadlineMs = 60_000 } = {}) {
    this.base = new URL(base);
    this.compileDeadlineMs = compileDeadlineMs;
    this.nextId = 1;
    this.startCompiler();
    this.spare = this.spawn();
  }
  worker(role) { return new Worker(new URL(`runner/browser-worker.mjs?role=${role}`, this.base), { type: "module" }); }
  runtime(name) { return new URL(`runtime/${name}`, this.base).href; }

  // The compile worker can die: an error, a "fatal", or no answer before the compile deadline. Every compile
  // waiting on it then gets a "crash" answer instead of waiting forever, and the next compile gets a fresh worker.
  startCompiler() {
    const c = { w: this.worker("compile"), pending: new Map(), dead: null };
    c.ready = new Promise((resolve, reject) => { c.resolve = resolve; c.reject = reject; });
    c.ready.catch(() => {}); // compile() reports a failed start
    c.w.onmessage = (e) => {
      const m = e.data;
      if (m.type === "ready") c.resolve(m.ms);
      else if (m.type === "compiled") { const settle = c.pending.get(m.id); c.pending.delete(m.id); settle?.(m); }
      else if (m.type === "fatal") this.compilerDied(c, m.message);
    };
    c.w.onerror = (e) => { e.preventDefault(); this.compilerDied(c, e.message || "error"); };
    c.w.postMessage({ type: "init", compilerWasm: this.runtime("compiler.wasm"),
      sdk: this.runtime("compile-classlib-teavm.bin"), classlib: this.runtime("runtime-classlib-teavm.bin") });
    this.compiler = c;
  }
  compilerDied(c, message) {
    if (c.dead) return;
    c.dead = message;
    c.w.terminate();
    c.reject(new Error(message));
    for (const settle of c.pending.values()) settle({ ok: false, stage: "crash", crash: `compile worker died: ${message}`, diagnostics: [] });
    c.pending.clear();
    if (this.compiler === c) this.startCompiler();
  }
  async compile(source, strictMode = true) {
    const c = this.compiler;
    try { await c.ready; } catch (e) { return { ok: false, stage: "crash", crash: `compile worker died: ${e.message}`, diagnostics: [] }; }
    const id = this.nextId++;
    return new Promise((resolve) => {
      const timer = setTimeout(() => this.compilerDied(c, `no answer within ${this.compileDeadlineMs} ms`), this.compileDeadlineMs);
      c.pending.set(id, (m) => { clearTimeout(timer); resolve(m); });
      c.w.postMessage({ type: "compile", id, source, strictMode });
    });
  }

  spawn() {
    const w = this.worker("run");
    return {
      w,
      ready: new Promise((resolve) => { w.onmessage = (e) => { if (e.data.type === "spawned") resolve(); }; }),
      death: new Promise((resolve) => { w.onerror = (e) => { e.preventDefault(); resolve(e.message || "error"); }; }),
    };
  }
  // wasm is transferred to the run worker, so a caller that runs one program again (replay) passes a copy.
  // onOut/onErr receive the output as it arrives, in pieces, not lines. signal: an AbortSignal; aborting ends
  // the run at once with status "canceled".
  async run(wasm, { stdin = "", final = true, deadlineMs = 5000, randomSeed, outputLimitChars, outputLimitLines,
      onOut, onErr, signal } = {}) {
    const { w, ready, death } = this.spare;
    this.spare = this.spawn();
    await Promise.race([ready, death]);
    let stdout = "", stderr = "", limit = null, settled = false, exitCode = null, timer = null;
    const t0 = performance.now();
    return new Promise((resolve) => {
      const finish = (status, exception) => {
        if (settled) return;
        settled = true;
        clearTimeout(timer);
        signal?.removeEventListener("abort", cancel);
        w.terminate();
        const line = javaLineFor(status, exception);
        // After anything the program already wrote to stderr, where the JDK prints it (runtime/test/runner-faults.mjs).
        if (line) { stderr += line + "\n"; onErr?.(line + "\n"); }
        resolve({ status, exception, exitCode, stdout, stderr, ms: performance.now() - t0 });
      };
      const cancel = () => finish("canceled", null);
      if (signal?.aborted) return cancel();
      signal?.addEventListener("abort", cancel);
      timer = setTimeout(() => finish(limit ? "output-limit" : "timeout", null), deadlineMs);
      death.then((message) => finish("crashed", { message }));
      w.onmessage = (e) => {
        const m = e.data;
        if (m.type === "out") { stdout += m.text; onOut?.(m.text); }
        else if (m.type === "err") { stderr += m.text; onErr?.(m.text); }
        else if (m.type === "limit") limit = m;
        else if (m.type === "done") {
          exitCode = m.exitCode == null ? null : m.exitCode & 0xff;
          const exited = exitCode ? `exit-${exitCode}` : "ok";
          finish(m.limited ? "output-limit" : m.needsInput ? "needs-input" : m.exception ? "trap" : exited, m.exception);
        } else if (m.type === "fatal") finish("fatal", { message: m.message });
      };
      const bytes = typeof stdin === "string" ? new TextEncoder().encode(stdin) : stdin;
      w.postMessage({ type: "run", wasm, stdin: bytes, final, randomSeed, outputLimitChars, outputLimitLines,
        deobfuscator: this.runtime("compiler.wasm-deobfuscator.wasm") }, [wasm.buffer]);
    });
  }
  async compileAndRun(source, opts = {}) {
    const c = await this.compile(source, opts.strictMode !== false);
    if (!c.ok) return { compile: c, status: "compile-error", stdout: "", stderr: "" };
    return { compile: { ok: true, ms: c.ms }, ...(await this.run(c.wasm, opts)) };
  }
  close() { this.compiler.w.terminate(); this.spare.w.terminate(); }
}

// The build's transcript rules (build/Audit.java: tidy, stdoutFromTranscript, and the stderr half of stated),
// character for character, so the page, the replay test and the build agree on what "the same output" means.
export function tidy(s) {
  const lines = s.replace(/\r\n/g, "\n").replace(/\r/g, "\n").split("\n").map((l) => l.replace(/[ \t]+$/, ""));
  while (lines.length && lines[0] === "") lines.shift();
  while (lines.length && lines[lines.length - 1] === "") lines.pop();
  return lines.join("\n");
}
// A stated sample run shows each typed answer on its own line; the program's own stdout does not.
export function stdoutFromTranscript(transcript, typed) {
  let t = tidy(transcript) + "\n";
  let pos = 0;
  for (const answer of typed) {
    const at = t.indexOf(answer + "\n", pos);
    if (at < 0) throw new Error(`the stated sample run does not show the typed answer "${answer}"`);
    t = t.slice(0, at) + t.slice(at + answer.length + 1);
    pos = at;
  }
  return t;
}
// What a terminal shows of stderr after an uncaught exception: its first line and the program's own frames.
const OWN_FRAME = /^\tat [^()]*\(Main\.java:\d+\)$/;
export function statedStderr(stderr) {
  if (!stderr.startsWith("Exception in thread")) return "";
  const lines = stderr.split("\n");
  return [lines[0], ...lines.slice(1).filter((l) => OWN_FRAME.test(l))].map((l) => l + "\n").join("");
}

// Keyboard input by replay (D16). A Run goes until the program asks a question it has no answer for; the reader
// answers in place; the program runs again from the start with every answer so far. One seed for the whole Run
// keeps Random and Math.random the same across replays. Works with NodeRunner and BrowserRunner alike.
import { statedStderr } from "./transcript.mjs";

export class Replay {
  // wasm: the compiled program; run() transfers what it is given, so every run gets a copy.
  // runOptions go to every run (randomSeed, deadlineMs, caps, onOut, onErr, signal); stdin and final are ours.
  constructor(runner, wasm, runOptions = {}) {
    this.runner = runner;
    this.wasm = wasm;
    this.runOptions = runOptions;
    this.answers = [];
    this.pauses = []; // pauses[i]: how much the program had printed when it asked for answer i
    this.result = null;
    this.diverged = false;
  }
  start() { return this.step(false); }
  answer(text) { this.answers.push(text); return this.step(false); }
  endInput() { return this.step(true); } // Ctrl-D: the answers so far are all there will be
  async step(final) {
    const stdin = this.answers.map((a) => a + "\n").join("");
    const before = this.result;
    const r = await this.runner.run(this.wasm.slice(), { ...this.runOptions, stdin, final });
    // A replay must print again exactly what the last run printed before its question.
    if (before?.status === "needs-input" && !r.stdout.startsWith(before.stdout)) this.diverged = true;
    if (r.status === "needs-input") this.pauses[this.answers.length] = r.stdout.length;
    this.result = r;
    return this;
  }
  get waiting() { return this.result?.status === "needs-input"; }
  get segments() {
    const out = [], s = this.result?.stdout ?? "";
    let at = 0;
    for (let i = 0; i < this.answers.length; i++) {
      const p = this.pauses[i];
      if (p === undefined) break; // answered after Ctrl-D or a divergence: nothing more to place
      out.push({ kind: "out", text: s.slice(at, p) }, { kind: "typed", text: this.answers[i] + "\n" });
      at = p;
    }
    out.push({ kind: "out", text: s.slice(at) });
    return out.filter((x) => x.text);
  }
  get transcript() { return this.segments.map((x) => x.text).join(""); }
  get shown() { return this.transcript + statedStderr(this.result?.stderr ?? ""); }
}
```

### Task 5: Check's harness, its plain-words errors, and its verdicts

DESIGN section 3 and D17, with D39: the reader's file stays a compact source file. Check renames the reader's own
`main` so it never runs, appends a generated `main` that calls the exercise's method once per case, each case in its
own `try`/`catch`, and compares inside Java. Case values are Java source text written into the generated code; nothing
is converted between JavaScript and Java values (the Python course's 2e05eb9 lesson). A signature the reader changed
comes back as `javac`'s error, which Check translates into plain words.

**Files:**
- Create: `web/page/check.mjs`, `web/test/check.mjs`

**Interfaces:**
- Consumes: a runner (`NodeRunner` or `BrowserRunner`) and `web/page/transcript.mjs`'s `tidy`.
- Produces: `web/page/check.mjs`:
  - `methodHarness(source, check) -> { source, reader, readerLines, calls, mark }` for a method check
    `{ kind: "method", name, returns, params, cases: [[args, expected], ...] }` (all strings of Java source).
    `calls[i]` is `{ line, open }`: the generated line of case `i` and the 1-based column of its call's `(`. `reader` is
    the reader's file with its main renamed; `mark` is a random marker made per call, written into the generated code
    and printed after a newline at the start of every line the generated main prints, so a reader's partial line never
    joins one and a line the reader prints cannot forge one.
  - `explainCompile(diagnostics, harness, check) -> { kind: "reader", diagnostics } | { kind: "signature", message } |
    { kind: "unclear", cause, message }`: "unclear" is an error on a generated line that is none of the signature
    shapes (a brace the reader dropped or added puts javac's parse error there). `runCheck` never returns it: it
    compiles the reader's file alone with a stub main and answers "signature" if that compiles or fails on the same
    error, else "reader" with that compile's diagnostics.
  - `methodVerdict(result, harness, check) -> { passed, lines: [{ ok, text }], stopped?, compile? }`.
  - `outputVerdict(printed, expected)`, `predictVerdict(prediction, expected)` -> `{ passed, text }`.
  - `inputVerdict(results, runs) -> { passed, lines: [{ ok, text }] }` for an input check
    `{ kind: "input", runs: [{ typed: [...], numbers?: [...], words?: [...], contains? }] }`.
  - `runCheck(runner, source, check, { deadlineMs = 5000, signal }) -> verdict`: compiles and runs what the check
    needs (method: the harness; output: the program; input: the program once per run, stdin final) and returns the
    kind's verdict. A predict check needs no run: `runCheck` is not used for it.

// Check (DESIGN section 3, D17, D39). The reader's file stays a compact source file: Check renames the reader's own
// main so it never runs, and appends a generated main that calls the exercise's method once per case, each case in
// its own try/catch, comparing inside Java. Case values are Java source text written into the generated code;
// nothing is converted between JavaScript and Java values. A signature the reader changed comes back as javac's
// error, which explainCompile puts in plain words. Works with NodeRunner and BrowserRunner alike.
import { tidy } from "./transcript.mjs";

const MARK = "\u001fjf "; // starts every line the generated main prints, so the program's own output never counts
const MAIN_DECL = /\bvoid(\s+)main(\s*)\(/g; // also renamed inside a comment or string: harmless, main never runs
const HELPERS = [
  "void jf$report(int i, Object got, Object want) {",
  '  System.out.println("\\u001fjf " + i + (java.util.Objects.deepEquals(got, want) ? " ok" : " fail " + jf$show(got)));',
  "}",
  "void jf$threw(int i, Throwable t) {",
  '  System.out.println("\\u001fjf " + i + " threw " + t.getClass().getName() + (t.getMessage() == null ? "" : ": " + t.getMessage()));',
  "}",
  "String jf$show(Object o) {",
  '  if (o == null) return "null";',
  '  if (o instanceof String s) return "\\"" + s.replace("\\\\", "\\\\\\\\").replace("\\"", "\\\\\\"").replace("\\n", "\\\\n") + "\\"";',
  '  if (o instanceof Character c) return "\'" + c + "\'";',
  '  if (o.getClass().isArray()) { String s = java.util.Arrays.deepToString(new Object[] { o }); return s.substring(1, s.length() - 1); }',
  "  return String.valueOf(o);",
  "}",
];

export function methodHarness(source, check) {
  const reader = (source.endsWith("\n") ? source : source + "\n").replace(MAIN_DECL, "void$1jf$m$2(");
  const readerLines = reader.split("\n").length - 1;
  const lines = ["void main() {"], calls = [];
  check.cases.forEach(([args, expected], i) => {
    const before = `  try { ${check.returns} jf$got = ${check.name}`;
    lines.push(`${before}(${args}); ${check.returns} jf$want = ${expected}; jf$report(${i}, jf$got, jf$want); } catch (Throwable jf$t) { jf$threw(${i}, jf$t); }`);
    calls.push({ line: readerLines + lines.length, open: before.length + 1 });
  });
  lines.push('  System.out.println("\\u001fjf done");', "}", ...HELPERS);
  return { source: reader + lines.join("\n") + "\n", readerLines, calls };
}

const simple = (t) => t.trim().replace(/\bjava\.lang\./g, "");
const signature = (check) => `${check.returns} ${check.name}(${check.params.join(", ")})`;
const takes = (check) => `(${check.params.join(",")})`;

// An error on a generated line means the method is not what the exercise needs: that is the root cause, even when
// the reader's own (renamed) main fails too, as it does when it still calls the old signature. With no error on a
// generated line, every error is the reader's own, shown on their own lines.
export function explainCompile(diagnostics, harness, check) {
  const d = diagnostics.find((x) => x.phase === "javac" && x.line != null && x.line > harness.readerLines);
  if (!d) return { kind: "reader", diagnostics };
  const need = ` The exercise needs: ${signature(check)}.`;
  const msg = d.message;
  const call = harness.calls.find((c) => c.line === d.line);
  let m;
  if (/^cannot find symbol/.test(msg) && /symbol:\s+method /.test(msg))
    return { kind: "signature", message: `Check could not find a method ${check.name} that takes ${takes(check)}.${need}` };
  if ((m = /^incompatible types: (?:possible lossy conversion from )?(.+?) (?:cannot be converted )?to (.+)$/s.exec(msg)) && call) {
    if (d.column === call.open) return { kind: "signature", message: `${check.name} should return ${simple(m[2])}, but yours returns ${simple(m[1])}.${need}` };
    return { kind: "signature", message: `${check.name}'s parameter should be ${simple(m[1])}, but yours takes ${simple(m[2])}.${need}` };
  }
  if ((m = /cannot be applied to given types;[\s\S]*required:\s*(.*)\n\s*found:\s*(.*)/.exec(msg))) {
    const req = m[1].trim() === "no arguments" ? "()" : `(${simple(m[1]).replace(/\s+/g, "")})`;
    return { kind: "signature", message: `Check calls ${check.name} with ${takes(check)}, but your ${check.name} takes ${req}.${need}` };
  }
  return { kind: "signature", message: `Check could not call ${check.name}: ${msg.split("\n")[0]}.${need}` };
}

function parseCases(stdout, n) {
  const cases = new Array(n).fill(null);
  let finished = false;
  for (const line of stdout.split("\n")) {
    if (!line.startsWith(MARK)) continue;
    const rest = line.slice(MARK.length);
    if (rest === "done") { finished = true; continue; }
    const m = /^(\d+) (ok|fail|threw)(?: (.*))?$/.exec(rest);
    if (m && Number(m[1]) < n) cases[Number(m[1])] = { outcome: m[2], detail: m[3] ?? "" };
  }
  return { cases, finished };
}

function stopReason(result, call, deadlineMs) {
  const why = result.status === "timeout" ? `it ran for more than ${Math.round(deadlineMs / 1000)} seconds. An endless loop?`
    : result.status === "output-limit" ? "it printed too much."
    : (result.stderr ?? "").includes("java.lang.StackOverflowError") ? "StackOverflowError. Does your method call itself without end?"
    : (result.stderr ?? "").includes("java.lang.OutOfMemoryError") ? "OutOfMemoryError."
    : /^exit-/.test(result.status) ? "your method called System.exit."
    : "the program stopped unexpectedly.";
  return `Check stopped while running ${call}: ${why}`;
}

export function methodVerdict(result, harness, check, deadlineMs = 5000) {
  if (result.status === "compile-error") return { passed: false, lines: [], compile: explainCompile(result.compile.diagnostics, harness, check) };
  const { cases, finished } = parseCases(result.stdout, check.cases.length);
  const lines = [];
  for (let i = 0; i < check.cases.length; i++) {
    const [args, expected] = check.cases[i], c = cases[i], call = `${check.name}(${args})`;
    if (!c) return { passed: false, lines, stopped: stopReason(result, call, deadlineMs) };
    lines.push(c.outcome === "ok" ? { ok: true, text: `${call} -> ${expected}` }
      : c.outcome === "fail" ? { ok: false, text: `${call} returned ${c.detail}, expected ${expected}` }
      : { ok: false, text: `${call} threw ${c.detail}` });
  }
  if (!finished) return { passed: false, lines, stopped: stopReason(result, `${check.name}(...)`, deadlineMs) };
  return { passed: lines.every((l) => l.ok), lines };
}

function firstDifference(a, b, said) {
  const x = tidy(a).split("\n"), y = tidy(b).split("\n");
  for (let i = 0; i < Math.max(x.length, y.length); i++) {
    if (x[i] === y[i]) continue;
    if (said) return `Line ${i + 1}: you said ${x[i] ?? "nothing"}, it prints ${y[i] ?? "nothing"}`;
    if (x[i] === undefined) return `The output stops after line ${i}. Line ${i + 1} should be: ${y[i]}`;
    if (y[i] === undefined) return `Line ${i + 1} should not be there: ${x[i]}`;
    return `Line ${i + 1} is: ${x[i]}\nIt should be: ${y[i]}`;
  }
  return null;
}
export function outputVerdict(printed, expected) {
  const d = firstDifference(printed, expected, false);
  return d ? { passed: false, text: d } : { passed: true, text: "Correct." };
}
export function predictVerdict(prediction, expected) {
  const d = firstDifference(prediction, expected, true);
  return d ? { passed: false, text: d } : { passed: true, text: "Correct." };
}

// Input exercises are judged on what they print, not how: the pinned numbers must appear in order (a decimal
// within 0.005), the pinned words in order (any case), and `contains` as written.
const inOrder = (items, wanted, same) => { let i = 0; for (const x of items) if (i < wanted.length && same(x, wanted[i])) i++; return i === wanted.length; };
export function inputVerdict(results, runs) {
  const lines = runs.map((run, k) => {
    const res = results[k], said = run.typed.length ? `With input ${run.typed.join(", ")}` : "With no input";
    if (res.status !== "ok") return { ok: false, text: `${said}: the program stopped (${res.status})${(res.stderr ?? "").split("\n")[0] ? ": " + res.stderr.split("\n")[0] : ""}` };
    const out = res.stdout;
    if (run.numbers && !inOrder(out.match(/-?\d+(?:\.\d+)?/g) ?? [], run.numbers, (g, w) => Math.abs(Number(g) - Number(w)) <= 0.005))
      return { ok: false, text: `${said}: expected the numbers ${run.numbers.join(", ")} in order, and the output was:\n${out}` };
    if (run.words && !inOrder(out.toLowerCase().split(/[^\p{L}\p{N}]+/u), run.words.map((w) => w.toLowerCase()), (g, w) => g === w))
      return { ok: false, text: `${said}: expected the words ${run.words.join(", ")} in order, and the output was:\n${out}` };
    if (run.contains != null && !out.includes(run.contains))
      return { ok: false, text: `${said}: expected the output to contain ${run.contains}, and it was:\n${out}` };
    return { ok: true, text: `${said}: correct` };
  });
  return { passed: lines.every((l) => l.ok), lines };
}

export async function runCheck(runner, source, check, { deadlineMs = 5000, signal } = {}) {
  if (check.kind === "method") {
    const h = methodHarness(source, check);
    const result = await runner.compileAndRun(h.source, { deadlineMs, signal, final: true });
    return methodVerdict(result, h, check, deadlineMs);
  }
  const c = await runner.compile(source);
  if (!c.ok) return { passed: false, lines: [], compile: { kind: "reader", diagnostics: c.diagnostics } };
  if (check.kind === "output") {
    const r = await runner.run(c.wasm, { deadlineMs, signal, final: true });
    return r.status === "ok" ? outputVerdict(r.stdout, check.expected) : { passed: false, text: `The program stopped (${r.status}).` };
  }
  if (check.kind === "input") {
    const results = [];
    for (const run of check.runs)
      results.push(await runner.run(c.wasm.slice(), { stdin: run.typed.map((t) => t + "\n").join(""), final: true, deadlineMs, signal }));
    return inputVerdict(results, check.runs);
  }
  throw new Error(`runCheck: no run for a ${check.kind} check`);
}

    appears twice.

`javacText` is exact behavior; write it as given:
```js
// A compile error as javac prints it at a terminal: "Main.java:<line>: error: <the message's first line>", the source
// line, a caret under the column, the message's other lines, then the count.
export function javacText(diagnostics, source) {
  const lines = source.split("\n");
  const shown = diagnostics.filter((d) => !/warn|note/i.test(d.severity));
  const text = shown.map((d) => {
    const [first, ...rest] = String(d.message).split("\n");
    const more = rest.map((l) => l + "\n").join("");
    if (d.line == null) return `error: ${first}\n${more}`;
    const caret = d.column != null ? " ".repeat(Math.max(0, d.column - 1)) + "^\n" : "";
    return `Main.java:${d.line}: error: ${first}\n${lines[d.line - 1] ?? ""}\n${caret}${more}`;
  });
  return text.join("") + `${shown.length} error${shown.length === 1 ? "" : "s"}\n`;
}
```
