ANSWER KEY


VOCABULARY
----------

 1. The line int[] scores = {88, 92, 79}; makes one ____: many values of
    one type, held in one variable, in order, with a length fixed when it
    is made.

      ANSWER: array

 2. Each item in an array or a list has a position called its ____. Java
    counts these starting from zero.

      ANSWER: index

 3. The property that lets an array's items be changed after it is
    created, unlike the letters of a String, is called ____.

      ANSWER: mutability

 4. Taking a section of an array into a new array, as
    Arrays.copyOfRange(letters, 1, 4) does, is called ____. The original
    array is left untouched.

      ANSWER: slicing


READING CODE
------------

 5. What does this print?

        String[] names = {"Ada", "Grace", "Alan", "Katherine"};
        IO.println(names[1]);
        IO.println(names[names.length - 1]);

      ANSWER: Grace
          Katherine

 6. What does this print?

        String[] letters = {"a", "b", "c", "d", "e", "f"};
        IO.println(Arrays.toString(Arrays.copyOfRange(letters, 2, 5)));
        IO.println(Arrays.toString(Arrays.copyOfRange(letters, 0, 2)));

      ANSWER: [c, d, e]
          [a, b]

 7. What does this print?

        ArrayList<Integer> scores = new ArrayList<>(List.of(88, 92, 79));
        ArrayList<Integer> ordered = new ArrayList<>(scores);
        Collections.sort(ordered);
        IO.println(ordered);
        IO.println(scores);

      ANSWER: [79, 88, 92]
          [88, 92, 79]

 8. What does this print?

        ArrayList<Integer> a = new ArrayList<>(List.of(1, 2, 3));
        ArrayList<Integer> b = a;
        b.add(4);
        IO.println(a);

      ANSWER: [1, 2, 3, 4]

 9. What does this print?

        String[] names = {"Ada", "Grace", "Alan"};
        for (int i = 0; i < names.length; i++) {
            IO.println((i + 1) + ". " + names[i]);
        }

      ANSWER: 1. Ada
          2. Grace
          3. Alan

10. What does this print?

        int[] scores = {55, 82, 91, 40, 76};
        ArrayList<Integer> passing = new ArrayList<>();
        for (int score : scores) {
            if (score >= 60) {
                passing.add(score);
            }
        }
        IO.println(passing);
        IO.println(passing.size());

      ANSWER: [82, 91, 76]
          3

12. Complete the line so that it sorts the copy, leaving scores as it
    was:
    ArrayList<Integer> scores = new ArrayList<>(List.of(88, 92, 79));
    ArrayList<Integer> ordered = new ArrayList<>(scores);
    ____(ordered);
    IO.println(ordered + " " + scores); // [79, 88, 92] [88, 92, 79]
