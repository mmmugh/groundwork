 1. A ____ method is one that calls itself, as long as it always calls
    itself on a smaller version of the problem and knows when to stop.

      ANSWER: recursive

 2. The ____ is a version of the problem small enough to answer outright,
    with no further call.

      ANSWER: base case

 3. The ____ calls the method again on a smaller input and builds the
    answer from the result.

      ANSWER: recursive case

 4. Recursion is not a loop that goes around; it is a ____ of unfinished
    work that unwinds.

      ANSWER: stack

 5. Remembering answers already computed, so they are never recalculated,
    is a technique called ____.

      ANSWER: memoization

 9. What does this print?

        int factorialTraced(int n) {
            return factorialTraced(n, 0);
        }

        int factorialTraced(int n, int depth) {
            String indent = "  ".repeat(depth);
            IO.println(indent + "factorial(" + n + ") called");

            if (n <= 1) {
                IO.println(indent + "base case, returning 1");
                return 1;
            }

            int result = n * factorialTraced(n - 1, depth + 1);
            IO.println(indent + "returning " + n + " * factorial("
                    + (n - 1) + ") = " + result);
            return result;
        }

        void main() {
            factorialTraced(2);
        }

      ANSWER: factorial(2) called
            factorial(1) called
            base case, returning 1
          returning 2 * factorial(1) = 2
