VOCABULARY

 1. A ____ stores a connection between a key and a value directly, so a
    lookup doesn't depend on two arrays staying in the same order.

      ANSWER: map

 2. In scores.put("Ada", 88), "Ada" is the ____, which you look things up
    by, and 88 is the ____ it leads to.

      ANSWER: key
      ANSWER: value

 3. A ____ is a collection with no duplicates, best suited to answering
    one question: is this thing in here?

      ANSWER: set

 4. A ____ is a small method with no name, such as e -> e.getValue(),
    often passed to Comparator.comparing to sort a list.

      ANSWER: lambda

 7. What does this print?

        String text = "a b a c b a";
        Map<String, Integer> counts = new LinkedHashMap<>();
        for (String word : text.split(" ")) {
            counts.put(word, counts.getOrDefault(word, 0) + 1);
        }
        IO.println(counts);

      ANSWER: {a=3, b=2, c=1}

 9. What does this print?

        Set<String> band = Set.of("Ada", "Grace", "Alan");
        Set<String> chorus = Set.of("Grace", "Alan", "Katherine");
        Set<String> both = new HashSet<>(band);
        both.retainAll(chorus);
        IO.println(both.size());
        Set<String> bandOnly = new HashSet<>(band);
        bandOnly.removeAll(chorus);
        IO.println(bandOnly.contains("Ada"));

      ANSWER: 2

10. What does this print?

        Map<String, String> ada = new LinkedHashMap<>();
        ada.put("score", "88");
        ada.put("grade", "B");
        Map<String, String> grace = new LinkedHashMap<>();
        grace.put("score", "92");
        grace.put("grade", "A");
        Map<String, Map<String, String>> students =
                new LinkedHashMap<>();
        students.put("Ada", ada);
        students.put("Grace", grace);
        for (String name : students.keySet()) {
            Map<String, String> info = students.get(name);
            String score = info.get("score");
            String grade = info.get("grade");
            IO.println(name + ": " + score + " (" + grade + ")");
        }

      ANSWER: Ada: 88 (B)
          Grace: 92 (A)
