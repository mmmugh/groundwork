VOCABULARY
----------

 1. A ____ is a type of your own that holds a fixed set of named values
    together and cannot be changed after it is made.

      ANSWER: record

 2. In point.x(), the method x() is the record's ____ for its x component:
    a method named after the component that gives back its value.

      ANSWER: accessor

 3. Real data is usually a collection of records, and in Java that is
    represented as a ____, such as ArrayList<Student>.

      ANSWER: list of records (an ArrayList of records is also right)

 4. final int LOW_STOCK = 10; is written in capitals, the Java convention
    for a ____ - a value fixed for the whole program.

      ANSWER: constant

 5. The line String state = left == 0 ? "OUT OF STOCK" : left + " left";
    uses a ____ - an if/else that produces a value rather than choosing
    statements.

      ANSWER: conditional expression

 9. What does this print?

        record Range(int lowest, int highest) {}

        Range minMax(int[] numbers) {
            int lowest = numbers[0];
            int highest = numbers[0];
            for (int number : numbers) {
                if (number < lowest) {
                    lowest = number;
                }
                if (number > highest) {
                    highest = number;
                }
            }
            return new Range(lowest, highest);
        }

        void main() {
            int[] numbers = {5, 2, 9, 1};
            Range result = minMax(numbers);
            IO.println(result);
            IO.println(result.highest());
        }

      ANSWER: Range[lowest=1, highest=9]
          9

10. What does this print?

        record Student(String name, int grade) {}

        Student findStudent(ArrayList<Student> students, String name) {
            for (Student student : students) {
                if (student.name().equals(name)) {
                    return student;
                }
            }
            return null;
        }

        void main() {
            ArrayList<Student> students = new ArrayList<>(List.of(
                    new Student("Ada", 9), new Student("Grace", 10)));
            Student found = findStudent(students, "Alan");
            if (found != null) {
                IO.println(found.grade());
            } else {
                IO.println("Not found.");
            }
            IO.println(findStudent(students, "Grace"));
        }

      ANSWER: Not found.
          Student[name=Grace, grade=10]
