Chapter 3 - Expressions and Operators

ANSWER KEY


VOCABULARY
----------

 1. An ____ is anything Java can work out to produce a single value,
    such as 7 or 3 + 4.

      ANSWER: expression

 2. Java ____ an expression, reducing it down to one value.

      ANSWER: evaluates

 3. The first argument of String.format, the text with placeholders
    starting with %, is called the ____.

      ANSWER: format string

 4. The %.2f inside a format string is called a ____: it controls how
    the value is displayed.

      ANSWER: format specifier


READING CODE
------------

 5. What does this print?

        IO.println((17 / 5) + " " + (17 % 5) + " " + (17 / 5.0));

      ANSWER: 3 2 3.4

 6. What does this print?

        IO.println(10 + 3 * 2);
        IO.println((10 + 3) * 2);
        IO.println(Math.pow(2, 3) * 4);

      ANSWER: 16
          26
          32.0

 7. What does this print?

        String name = "Ada";
        double score = 91.5;
        IO.println(String.format("%s scored %.1f points.", name, score));

      ANSWER: Ada scored 91.5 points.

 8. What does this print?

        IO.println("-".repeat(10));
        IO.println("ab".repeat(3));

      ANSWER: ----------
          ababab

 9. What does this print?

        int score = 0;
        score += 10;
        score += 25;
        score *= 2;
        IO.println(score);

      ANSWER: 70

10. What does this print?

        IO.println((7 / 2) + " " + (7 % 2) + " " + (7 / 2.0));
        IO.println(Math.pow(2, Math.pow(3, 2)));
        IO.println("5".repeat(3));
        IO.println(Integer.parseInt("5") * 3);

      ANSWER: 3 1 3.5
          512.0
          555
          15


WRITING CODE
------------

11. Complete this line so it prints 1024.0, which is 2 to the power 10:
    IO.println(____(2, 10));

      ANSWER: Math.pow

12. Complete this format string so a dollar total always shows exactly
    two decimal places:
    double total = 7.5;
    IO.println(String.format("Total: $____", total));

      ANSWER: %.2f

13. Rewrite x = x + 3; using the shorthand assignment operator:
    x ____ 3;

      ANSWER: +=


WHY IT WORKS
------------

14. 0.1 + 0.2 prints 0.30000000000000004 because computers store a double
    in ____, and just as 1/3 cannot be written exactly as a decimal, 0.1
    cannot be written exactly in that format either.

      ANSWER: binary

15. / on two ints drops the fraction by truncating toward ____, which is
    why -17 / 5 is -3 rather than -4.

      ANSWER: zero

16. ____ assigns a value to a variable, while ____ asks whether two values
    are equal and produces a boolean.

      ANSWER: =
      ANSWER: ==
