VOCABULARY

 1. A String is a ____ of characters, so charAt and substring count its
    positions from zero, as an array's indexes do.

      ANSWER: sequence

 2. Unlike an array, a String is ____: it cannot be changed after it is
    created, so every String method that seems to change it gives back a
    new String instead.

      ANSWER: immutable

 3. The String method ____ gives back true when another String appears
    anywhere inside it, and false when it does not.

      ANSWER: contains

 4. Sequences like \n and \t, which stand for characters that can't be
    typed directly into a string, are called ____ sequences.

      ANSWER: escape

10. What does this print?

        int countVowels(String text) {
            String lower = text.toLowerCase();
            int count = 0;
            for (int i = 0; i < lower.length(); i++) {
                char letter = lower.charAt(i);
                if ("aeiou".indexOf(letter) >= 0) {
                    count++;
                }
            }
            return count;
        }

        void main() {
            IO.println(countVowels("Hello World"));
        }

      ANSWER: 3
