VOCABULARY

 1. A ____ is an expression, written in parentheses after the if keyword,
    that produces true or false.

      ANSWER: condition

 2. The statements between a { and its }, which run only when the
    condition is true, are called a ____.

      ANSWER: block

 3. ____ (two words) lets you chain more than two possibilities together
    in one decision.

      ANSWER: else if

 4. In Java a condition must produce a ____ value, true or false, which is
    why if (name) is a compile error when name is a String.

      ANSWER: boolean

 5. What does this print?

        int score = 85;
        String grade;

        if (score >= 90) {
            grade = "A";
        } else if (score >= 80) {
            grade = "B";
        } else if (score >= 70) {
            grade = "C";
        } else if (score >= 60) {
            grade = "D";
        } else {
            grade = "F";
        }

        IO.println("Score " + score + " earns a " + grade + ".");

      ANSWER: Score 85 earns a B.

10. Complete this line so the age the user types is read as a whole
    number:
    int age = ____(IO.readln("Your age: ").strip());

      ANSWER: Integer.parseInt

11. Complete the catch so it handles the exception Integer.parseInt
    throws when it cannot read the text:
    try {
        int tickets = Integer.parseInt(answer.strip());
        IO.println("That will be $" + (tickets * 12) + ".");
    } catch (____ e) {
        IO.println("Please enter a whole number.");
    }

      ANSWER: NumberFormatException
